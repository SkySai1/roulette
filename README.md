# Онлайн рулетка

Приложение на React для запуска онлайн-рулетки с двумя режимами работы:

1. **Обычная рулетка** — случайно выбирает один из загруженных результатов.
2. **Распределяющая рулетка** — присваивает результаты участникам так, чтобы каждое значение встречалось только один раз.

## Возможности

- Редактирование списков участников и результатов (по строкам или через запятые).
- Выбор активного участника для распределяющего режима и фиксация выданных результатов.
- Сброс распределения в один клик.
- Адаптивный интерфейс с визуальным колесом и отображением таблицы результатов.

## Запуск

```bash
npm install
npm run dev
```

Сборка production-версии:

```bash
npm run build
npm run preview
```
